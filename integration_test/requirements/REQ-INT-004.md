# Avionics Update Rate Requirement

## REQ-INT-004

SIL: DAL-A | Sec: False | Version: 1

**Critical Update Rate**

The avionics system SHALL maintain the update rate defined by [@update_rate](/test_params.yaml?version=1#update_rate).

This requirement ensures deterministic real-time performance for flight-critical systems per DO-178C.
